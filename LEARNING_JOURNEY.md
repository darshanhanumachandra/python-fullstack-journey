## Struggles & Solutions
- **Struggle**: Understanding where data comes from in child classes
  - **Solution**: `super().__init__()` calls parent's __init__
- **Struggle**: When to use @abstractmethod
  - **Solution**: Use when child MUST implement the method
- **Struggle**: Polymorphism purpose
  - **Solution**: Allows one loop to work with multiple types automatically
